## 🔭 What I work on

- **Multi-agent workflows and RAG** over private data, connected to client APIs, databases and MCP tooling
- **LLM evaluation:** golden datasets, LLM-as-judge and release gates, so prompt changes can't silently break production
- **Guardrails for sensitive data:** pseudonymization before the model, access controls, human review where it matters
- **Serverless, event-driven systems** on AWS and Google Cloud

## 🏗️ Selected work

- **Multi-agent AI platform for a provincial government** (energy area): campaign generator, conversation simulator and legislation assistant. Visual prototype → pilot with real users in ~3 weeks → LangGraph in production in ~3 months, with an evaluation gate so non-technical staff could improve prompts safely.
- **Document agents for law firms:** OCR and Gemini on Google Cloud, with client data pseudonymized before it reaches any model.
- **Amazon Business launch in Australia (P0):** a seller-eligibility engine that kept search within strict P99 latency, with event-driven updates; 10,000+ B2B sellers unblocked before Day 1.
- **AWS:** serverless matching platform routing customer requests to Solutions Architects; 50%+ faster time-to-customer across 5,000+ US SAs.
